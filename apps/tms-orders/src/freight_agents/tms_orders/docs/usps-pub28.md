Plain-language summary written from the publication.

## Two-letter state abbreviations

Appendix B lists the two-letter abbreviations for the 50 states and the District of Columbia (AL, AK, AZ, AR, CA, CO, CT, DE, DC, FL, GA, HI, ID, IL, IN, IA, KS, KY, LA, ME, MD, MA, MI, MN, MS, MO, MT, NE, NV, NH, NJ, NM, NY, NC, ND, OH, OK, OR, PA, RI, SC, SD, TN, TX, UT, VT, VA, WA, WV, WI, WY), along with possessions and military codes.

## ZIP Code on the last line

The last line holds the city, the two-letter state abbreviation and either a Five-Digit ZIP Code or a ZIP+4 Code, which takes 10 positions: five digits, a hyphen and four digits.
