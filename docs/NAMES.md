## Rule

Every company and person in this repository is invented. Before a company name is used, it is checked against the FMCSA SAFER carrier register and a web search, so it does not belong to a real business. People use addresses at `example.com`, `example.net` or `example.org`, which are reserved for documentation (RFC 2606).
